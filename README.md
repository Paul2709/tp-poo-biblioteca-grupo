# Trabajo Práctico Grupal — Biblioteca POO

**Integrantes:** Paul Chavez

Sistema de gestión de biblioteca en Python con tres clases: `Libro`, `Socio` y `Biblioteca`.
Se respetan los nombres de clases y métodos establecidos por la consigna.

## Requisitos

* Python 3 (no requiere instalar bibliotecas externas).

## Cómo ejecutarlo

Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
python main.py
```

Se muestran ejemplos de préstamos y devoluciones y, al finalizar, el mensaje:

```text
¡Todas las pruebas pasaron!
```

## Archivos

* `libro.py`: propiedades de solo lectura, préstamo y devolución de libros.
* `socio.py`: registro de préstamos por socio, máximo tres libros.
* `biblioteca.py`: diccionarios de libros por ISBN y socios por DNI; coordinación de operaciones.
* `main.py`: demostración y pruebas automáticas de la Parte 4 de la consigna.
